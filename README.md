# 深云 Agent / DeepClub Agent

深云 Android 手机 Agent，基于 [DSH Go](https://github.com/ccch1mneyyy/dsh-Go) 修改，保留其本机 Linux / DeepSeek Harness 运行时与任务、工具、文件、终端和审批能力。登录深云后由服务端下发模型和凭据。

This repository maintains the DeepClub Android adaptation of DSH Go. It preserves the upstream Agent runtime and provides DeepClub account sign-in and managed model configuration. It is not an official DeepSeek product.

本仓库保存可复现的改造层、固定上游版本和构建说明，不复制上游受限品牌素材。产品与原作者及 DeepSeek 无隶属关系。实现进度见 [#1](https://github.com/meyaomiao/deepclub-mobile/issues/1)；完整方案见 [deepclub#444](https://github.com/meyaomiao/deepclub/issues/444)。

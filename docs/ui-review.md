# 深云移动端 UI 检查规范

适用于本仓库新增或修改的所有界面（`overlay/new/`、`overlay/replace/` 及补丁涉及的上游页面）。基础规范沿用上游 [polish-guide.md](https://github.com/ccch1mneyyy/dsh-Go/blob/288234ae52fdfcfc2b0a0388763c371d0b09ea7d/docs/design/polish-guide.md) 和 [page-design.md](https://github.com/ccch1mneyyy/dsh-Go/blob/288234ae52fdfcfc2b0a0388763c371d0b09ea7d/docs/design/page-design.md)。本文补充深云的品牌约定，并把加载状态写成可逐条检查的规则；两者冲突时，品牌相关以本文为准。

iOS 改造层（基于 Whaleness，见[适配方案 §7](adaptation-plan.md#7-ios-端基于-whaleness)）同样遵守本文。控件用平台原生实现，颜色、间距阶梯、图标风格、文案、状态用词和加载规则保持一致。

每条规则都应能回答「是 / 否」。PR 必须附 §11 要求的截图和检查结果。

## 1. 每屏检查顺序

1. 这一屏现在处于什么状态？加载、空、出错、离线、无权限、正常，**每种都要有设计过的样子**。
2. 同一块区域是否只有**一个**加载指示？（§2.1）
3. 状态切换时，其他内容是否跳动？（§2.6）
4. 是否只有一个视觉重心、一个主按钮？
5. 间距是否全部来自 `AppSpace`，同类元素是否等距？（§3）
6. 360dp 宽、字号 1.3、深色、英文下是否仍然成立？（§11）

## 2. 加载与进度（重点）

### 2.1 一处一个

- 同一块区域（一张卡片、一个页面主体、一个列表）在任意时刻**最多一个**进度指示：转圈、进度条、骨架三选一。
- 不确定进度（转圈 / 不定进度条）和确定进度（百分比进度条）**不能同时出现**。
- 页面顶栏下方的细进度条和内容区的转圈不能同时出现。

### 2.2 多阶段用一个阶段列表

登录后准备、扫码配对这类多步过程，用**一个阶段列表**代替多个独立指示：

```
✓  已登录深云
◔  准备运行环境        45%
○  启动引擎
○  同步模型
```

- 每行：状态图标（完成 / 进行中 / 等待 / 失败）+ 一句短文案 + 可选右侧数值。
- 只有「进行中」这一行有动态指示；能算出百分比就用确定进度。
- 完成的行淡化为次要文字色，不再闪动；失败的行显示原因，「重试」只出现在这一行或这张卡片底部，全屏只有一个。
- 不再在阶段列表上方或下方另放一个总进度条。

### 2.3 避免闪烁

- 预计 300 ms 内完成的操作不显示任何加载指示。
- 指示在操作开始 300 ms 后才出现；出现后至少保留 500 ms，避免一闪而过。
- 本地读取（设置、主机列表）造成的启动等待，沿用启动画面，不另画一屏转圈。

### 2.4 不整屏转圈

- 禁止 `Scaffold(body: Center(child: CircularProgressIndicator()))` 这类整屏转圈。
- 列表和卡片加载用**骨架**：骨架行高与最终行一致（单行 52、两行 64），数量 3–5 行。
- 局部等待用 `QuietSpinner`（20dp、描边 2、`textTertiary`），可带一行说明文字。

### 2.5 规格

| 类型 | 规格 |
|---|---|
| 小环 | `QuietSpinner`，20dp；按钮内 16dp |
| 进度条 | 高 4dp、圆端；宽度随内容列，居中卡片内最大 320dp；不铺满整屏 |
| 颜色 | 确定进度用主色；不确定进度与小环用 `textTertiary`，不用主色抢视线 |
| 骨架 | `surfaceContainerHighest` 底色，静态或极缓的明暗呼吸（≥ 1.2 s 周期），不做扫光 |

### 2.6 布局稳定

- 加载区域预留最终高度；加载 → 内容用 150–300 ms 淡变（`AnimatedSwitcher` + `AppMotion`），**其他内容不位移**。
- 禁止把 `LinearProgressIndicator` 作为列表第一项条件插入，否则每次出现或消失都会把整页推下或拉上。需要页级忙碌提示时，放在顶栏底边的叠加层，不占布局。
- 系统关闭动画时（`AppMotion.of` 返回 0），不定进度显示为静态文字状态。

### 2.7 按钮与次要操作

- 正在执行的按钮原位变成「小环 + 原文案」，并禁用该按钮；不要禁用整页无关按钮。
- 正常加载中，**不显示「重试」**；只有失败后才出现。可取消的操作只显示「取消」。
- 加载页上的次要入口（账号、远程设置等）收进右上角溢出菜单，不与进度并列堆叠。

### 2.8 文案

- 每个加载状态配一句说明「正在做什么」：「正在准备运行环境」，不写「请稍候…」。
- 超过 10 s 的过程显示阶段和百分比；超过 60 s 提示「可以先离开，完成后通知」。
- 不出现内部术语：rootfs、provision、agent-config、PKCE、carrier、RPC。

### 2.9 对话流式

沿用上游：正文 reveal、停顿时呼吸小点、工具运行中的细圆弧 `QuietArc`、完成画一个对勾。**不额外叠加**转圈、进度条或「思考中」横幅。

## 3. 布局与间距

| 规则 | 要求 |
|---|---|
| 间距来源 | 只用 `AppSpace`（2/4/8/12/16/20/24/32）；不写字面量 `SizedBox(height: 13)` |
| 页面留白 | 左右 16（`AppSpace.gutter`）；分组之间 24；分组标题到卡片 8 |
| 行高 | 单行 52、两行 64；点按区域 ≥ 48×48dp |
| 居中卡片 | 登录、准备、配对这类单任务页：内容列最大宽 520dp，垂直居中偏上（上留白约为下留白的 0.8 倍） |
| 等距 | 同类元素间距相同；标题与其内容的距离小于两组之间的距离 |
| 对称 | 胶囊、圆键、左右对应元素需几何测试，不目测 |
| 骨架 | 页面归入上游五种骨架之一；不使用原始 `Scaffold + AppBar` 自造页面 |
| 安全区 | 刘海、手势条、键盘弹起时主按钮不被遮挡 |

## 4. 状态完整性

每屏列出并逐一截图：

| 状态 | 要求 |
|---|---|
| 加载 | 符合 §2 |
| 空 | 一个图形 + 一句话 + 至多一个按钮 |
| 出错 | 一句话：发生了什么 + 怎么办；错误码放「详情」 |
| 离线 / 电脑离线 | 保留已有内容，顶部一条安静提示，自动重连 |
| 无权限 | 说明缺什么权限，按钮直达设置 |

账号相关额外状态：未登录、等待浏览器授权、准备中、已就绪、Key 无效或余额不足、设备已撤销、需要重新授权。

## 5. 文案与术语

- 遵守上游 polish-guide §3：短、确定、动词开头的按钮。
- 统一用词：深云、此手机、我的电脑、连接电脑、对话、工作区、引擎、思考深度。
- 界面不出现「DSH Go」「Whaleness」；来源声明只在「关于」页。
- 不展示 token、配对码、Key 或完整设备 ID。

## 7. 图标与颜色

- 图标只经 `AppIcons.<角色>` 使用；行内与胶囊用描边，选中态用 Fill。
- 主色朱红只给可点的主操作和品牌时刻；状态色只表示状态；大面积用中性色。
- 文字对比度 ≥ 4.5:1，大字和控件 ≥ 3:1；浅色、深色都要检查。
- 不写十六进制颜色，从主题取色。

## 8. 动效

遵守上游 polish-guide §2：150–300 ms，`AppMotion` 曲线；不做弹跳、扫光、循环装饰（进度指示除外）；动画不能引起布局抖动。

## 9. 无障碍

- 进度指示有 `Semantics`：确定进度播报百分比，阶段列表按顺序播报每步状态。
- 状态变化（准备完成、连接断开）用一次播报，不连续刷屏。
- 字号 1.3 和 2.0 下无溢出、无竖排折行；TalkBack 焦点顺序与视觉顺序一致。

## 10. 远程连接相关界面

- **运行位置胶囊**：始终显示当前是「此手机」还是哪台电脑，连接状态只用一个小点 + 一个词。
- **连接状态**固定六种：连接中、已连接、重新连接中、电脑离线、已撤销、版本不兼容。重连用顶部安静提示，不弹模态框，不清空已显示内容。
- **扫码页**：取景框居中；相机权限被拒时给出「去设置」，并保留「从相册识别」「粘贴配对码」；二维码过期提示「请在电脑上刷新二维码」。
- **配对成功**：一次性对勾动画后直接进入电脑的项目列表。
- **项目与文件**：列表骨架加载；电脑上无权限的文件夹显示「需要在电脑上允许访问」，不是空列表；路径用人读得懂的形式（`~/Documents/项目`），Windows 路径同样处理。
- 界面不显示配对码、设备 token 或完整 gatewayId。
